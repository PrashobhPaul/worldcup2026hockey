🎯 The Oracle

AI pre-match predictions · Published before kick-off · No edits, no deletions.

How the Oracle Works

Before every match, the Oracle publishes a prediction: which team wins, with a confidence % and key drivers. Predictions are logged to data/oracle.json before kick-off and never changed afterwards. After the match, the result is graded (✓ correct / ✗ wrong). The running accuracy builds the public record.

Inputs: FIH World Rankings · Recent form · Head-to-head · Pool stakes · Home advantage
Hockey.AI · Oracle accuracy is publicly verifiable. All picks timestamped at publication.
